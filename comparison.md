
# Сравнение собственной диаграммы с вариантом ИИ

## 1. Цель сравнения
Сравнить диаграмму вариантов использования системы «Бронирование аудиторий» с вариантом, предложенным искусственным интеллектом.

## 2. Сравнение диаграмм

| Критерий | Собственный вариант | Вариант ИИ |
|---|---|---|
| Название системы | Бронирование аудиторий | Бронирование аудиторий |
| Количество акторов | 3 | 3 |
| Количество вариантов использования | 6 | 6 |
| Проверка доступности | Используется при бронировании | Используется при бронировании |
| Заказ оборудования | Дополнительная функция | Дополнительная функция |
| Формирование отчёта | Отдельный вариант использования | Отдельный вариант использования |

## 3. Основные решения
В итоговой диаграмме предусмотрены три актора: сотрудник, диспетчер и университетское расписание.

Для проверки доступности аудитории используется отношение `<<include>>`, поскольку проверка является обязательной частью бронирования.

Для заказа оборудования используется отношение `<<extend>>`, поскольку это дополнительное действие, которое выполняется при необходимости.

Формирование отчёта о простое аудиторий представлено как отдельный вариант использования.

## 4. Преимущества выбранного решения
- Диаграмма содержит ограниченное количество элементов.
- Основные функции системы легко определить.
- Обязательные и дополнительные действия разделены.
- Структура диаграммы позволяет при необходимости добавлять новые функции.

## 5. Вывод
Сравнение помогает проверить полноту и понятность диаграммы. Перед сдачей необходимо сопоставить фактические схемы и внести реальные различия в таблицу, если они имеются.

Примечание: если преподаватель требует сравнить две готовые диаграммы, необходимо добавить изображения обеих схем. Описание ИИ не заменяет фактическое сравнение.
